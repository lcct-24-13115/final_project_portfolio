Maintenance Ticketing System

2026 · Class project

A web system for the school Maintenance Office. Staff file requests for materials or equipment, and each ticket moves through role-based approvals up to the school president.

My role: Solo developer. I built the whole system myself, including the forms, role dashboards, and approval flow.

Challenge
Requests for materials, equipment, and repairs have to pass through several offices before they are approved.
What I built
A Laravel system with three request forms, a dashboard for each role from requester to president, and a New, Doing, and Done board for the maintenance team.
Result
Every request can be followed from filing to approval to completion in one place, with alerts when it needs someone's attention.
  • Three request forms: facilities, requisition, and repairs
  • Separate dashboards for requester, maintenance, finance, custodian, and president
  • Maintenance board with New, Doing, and Done columns
  • Advance-notice rules and in-app alerts with sound
  • Laravel
  • PHP
  • MySQL
  • Blade

Integrated Library Management System

2026 · Class project

A library system for book loans and returns, patron profiles, reservations, attendance logging, borrowing history reports, and staff accounts with roles.

My role: Solo developer. I built the whole system myself, from the database to the reports.

Challenge
A library needs to track loans, returns, reservations, and visitors without losing records.
What I built
A Laravel system where staff scan the patron ID and accession number to issue or return a book, log attendance, and print loan, overdue, circulation, and shelf reports.
Result
Daily library work, from checkout to reports, runs from one system with role-based staff accounts.
  • Issue and return books by scanning the patron ID and accession number
  • Attendance logging with a visitors-per-hour chart
  • Printable reports: loan history, overdue list, circulation summary, and shelf list
  • Book reservations and patron profiles
  • Laravel
  • PHP
  • Blade
  • Tailwind CSS
